# Phase 12 美术方向（DRAFT，待人工验收）

基线 a4ea1fc。角色使用48×64透明像素帧，地面使用32×32格；纹理最近邻过滤。脚部为视觉锚点，不移动原碰撞圆、枪口或瞄准坐标。晋北使用冷石灰、旧木、暗铜与局部暖灯；博物馆使用暖木、玻璃、黄铜与清晰的真实中文控件。

素材由内置imagegen原创生成；不使用现实博物馆照片作为盗墓拾取图，不引入第三方插件。所有生成素材均为待验收草稿，不代表史学或真人美术审核通过。光照不得改变危险区、攻击前摇、机关线索或门状态的可读性。

优先保存旧绘制作为缺失素材和低配回退。背景、角色、展陈设施分层；禁止通过美术改造改变碰撞范围、房间拓扑、战斗或经营数值。
