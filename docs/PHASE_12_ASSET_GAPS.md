# Phase 12 素材缺口与人工待验

本轮交付是可玩视觉草稿和可回退架构，不是全游戏正式美术完成。

- 十位Boss保留各自原有机制图形，没有专属完整像素动画；BossVisual明确返回无专属素材，未放大普通敌人冒充Boss。
- 除尸蟞、盗墓枪手外的普通敌人及精英保留旧绘制。新两种敌人目前是六姿态帧，尚需更完整的方向与过渡动作。
- 玩家四方向素材已经实际接入，但北向部分步态/攻击姿态的一致性仍需返工；六姿态不等于完整高帧数动画。所有帧DRAFT待人工选择。
- 原8件古董有独立透明图；42件地区古董仍使用原分类小图，不套用旧8件图伪装完成。
- 晋北已有石板/墙体/棺木与原生灯光；火把实体、罐、壁龛、祭台、专属石门等完整环境道具组尚缺。部分不同形状障碍目前共用墙面纹理，拉伸与材质方向需要美术精修。
- 洛阳、关中保留已有地域装饰与轻量色调映射，尚没有完整的独立高质量环境素材组。
- 博物馆已替换主要家具/柜体和地面；库房、拍卖委托点、荣誉墙、通道及部分服务设施保留原图形。游客与导览员真实节点换装；鉴定员/修复师只按真实在职身份显示职业形象，不增加第二套员工AI。
- 地板已根据实机反馈式检查降噪，人物和材质是否达到统一HD-2D品质、灯光是否足够自然、立体遮挡是否舒适仍需真人验收。

未做正式图片授权定论、真人试玩、全面美术通过或全局性能保证。素材全部DRAFT；不继续新玩法阶段，不合并main。
