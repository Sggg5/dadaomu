## 范围与基线

## 机制与恢复

- BossDefinition新增boss_recovery_time / combo_recovery_time；普通恢复F1～F5为0.9/0.8/0.7/0.6/0.55秒，连段后1.05～1.1秒。纸将军沿原专用执行器1.3/1.1秒射击间隔。
- MechanismBoss记录最近8个Cycle是否组合，最多3个普通Cycle后优先高压；不读取玩家Build、生命值或经济状态。重复点射为有限子动作，最长队列4，实际为点射→冲锋两个战术动作。
- 阶段转换0.5秒，橙圈反馈；跨阈值第一击全额，随后0.4秒50%减伤，仍可致死。无硬血锁、无敌或每秒伤害限制。中断时预警/位移计划同时取消，不能无预警恢复旧攻击。
- 母巢2卵→0.5秒慢环→短冲；低血活卵最多2（多余卵无奖励退场）。常态卵上限仍4/总召唤有界。
- 老尸棺盖→手、冲撞→落点两侧手；半血组合比例提升。大帅近距离震→冲、中距离三点→冲、远距离点→兵→点；召兵不再单独休息。
- 铁索钩→0.55秒扫，能在0.6秒慢速效果结束前击中；危险铁索最多2条。百足卵→横穿或横穿→有限腐液→尾扫。
- 铜甲冲→砸 / 双砸→冲，撞墙后反向碎片仍保留2.5秒破甲；侧后正常伤害。双生轮流主攻，每3共享轮副方延迟1.1秒地圈；孤煞恢复时间×0.82、继承另一方技能、不回血。
- 镇兽Phase2组合，Phase3每轮组合，低25%刺→扇→扑，裂隙≤3；墓主人Phase2命令→本体，Phase3两崩塌区+一落石点→剑线→冲，停止新召兵。
- 纸将军HP不改，假身更常出现；半血交叉符和低血旋转配合，阶段取消旧预警并重建读招。
