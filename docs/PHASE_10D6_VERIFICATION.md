## 模型与容量

Museum（场景装配）→ExhibitionHallDefinition（稳定展厅）→DisplayUnitDefinition（陈列设施）→DisplaySlot（独立位置）→MuseumCollection中的OwnedAntique实例ID。节点只呈现当前展厅，保存中不保留Node。数据在data/museum/display_layout.json。

- MAIN主厅：CASE1小型4、CASE2/3标准各8，20位置。
- EAST东厅：Level0钱币柜16；Level1再开CASE4/5标准各8、书画展墙4。东厅由16升至36。
- WEST西厅：Level2 CASE6/7/8标准各8、大型展台1，25位置。
- 全馆Level0：2厅/4设施/36位置；Level1：2厅/7设施/56位置；Level2：3厅/11设施/81位置。
- 容量、类型、独立slot ID、最大尺寸、展厅、坐标与解锁等级可配置。不是把旧case_count改成100；旧3/5/8仅用于历史CASE身份兼容。可扩展更多厅/设施，无须创建每件藏品场景。

首批设施：小型4、标准8、钱币/小件16、展墙4（可配置）、大型展台1。八件原有游戏古董使用独立GAME_DESIGN_FOOTPRINT厘米占位配置，不是伪造真实博物馆测量；原.tres ID/数值未改。类型和三维尺寸匹配，不从背包slots推断体量。尺寸缺失/非法、类型不匹配、没有运输资格拒绝。原池没有书画/大型文物，墙/大型台当前可显示空设施；大型化石始终拒绝，因为没有合法运输系统。绘画匹配规则以纯数据夹具验证，不把新物品加入掉落。

## 操作、渲染与生命周期

E打开当前柜/墙/台的位置管理：全部位置、空位、名称、鉴定和品相；选位置+馆藏放入、撤下一件、批量撤整柜、按筛选填空位。同一实例跨任何厅/柜只允许一个位置；替换原位置不会删除馆藏。OPEN禁修改且所有修改按钮disabled，仍可查看。

库房支持中文名称/实例ID搜索、类型和鉴定/已陈列/待拍/可陈列状态筛选、稳定实例排序、50条分页。500件不一次生成500行控件，缩小筛选会钳制页码，避免空白末页。MuseumCollection新增实例索引，find按ID O(1)。固定设施优先近旁游客E交互，确保游客不挡住展柜管理；离开设施64px范围仍可交谈。移动参数未改。

实际走到展厅通道E、选择厅、进入/返回；只创建当前厅设施与碰撞体，切厅销毁旧设施节点，玩家、State、营业计时和馆藏保持。办公室/研究台/鉴定/修复/古董商/拍卖委托/库房/售票/情报板作为共享服务仍可使用。Prototype厅为明确ID的独立陈列空间，共用服务区和外形，不是一个大场景同时摆全部设施。

设施为原创2D木底座/支脚、斜面玻璃、黄铜框、分格托盘；已陈列实例分别画钱币/瓶/玉璧/镜/佛像/马等小图标。钱币柜真实4×4分格，不用覆盖的高矩形假装16格；没有未授权照片或AI冒充馆藏照片。管理面板单列槽位，完整名称与品相可读。

## 游客与经营

Visitor先按有效吸引力选厅，再选该厅设施；路线、当前hall_id、所看unit_id、逐件viewed_instance_ids独立于渲染Node。跨厅先沿450px通道到门口，再进入目标厅的合法路径。只在玩家同厅可见/可互动，不能访问已卸载展柜Node。当前配置单位都在通道上方，72px下方观看点不在设施脚座；实际模拟验证NPC未进任何本厅脚座且跨厅隐藏/显示正确。

同定义实例按实际品相基础吸引力从高到低、稳定实例ID排序，首件1.00，其后×0.65^n；默认无正数下限，取整数后尾部可为0，防无限重复堆收益。单件品相公式仍保持原规则（已鉴定至少1基础吸引力）；重复收益折减属于实际陈列全馆计算，与探索顺序/摆放位置无关。不同定义不互相折减。

访客目标 = base5 + floor(全馆有效吸引力×0.35) + 2×(有效展厅数−1)，然后夹在1和馆舍30/45/60容量。空陈列仍0，不增加门票价格（仍¥5）。设施权重为其中全部有效实际实例的吸引力。游客付一次、营业_paid再去重、关闭停止新客并等待现客离场；重复/迟到票款不改变现金。真实多件多厅营业、结算和观看八件均已验证。

全部ID/definition/获得日/品相/identified/现金/日期/level/campaign/当天票款/待拍锁和保留价/已有位置归属无损迁移。v1–3兼容逻辑继续保留。

读取不修改原档；合法迁移首次写v5前，创建`原路径.v4.源SHA前12位.backup.json`字节级备份（v1–3同样备份）。同名备份须hash一致，不覆盖不同旧备份。临时文件+原子替换后才更新存档版本。坏条目/未知布局/不合法归属/损坏JSON阻止自动保存，保留原字节；读取后外部改档同样拒绝覆盖。备份失败亦拒绝写。恢复须重新读取并通过验证，不自动拿空档覆盖失败原数据。
